# tiny-chess-01

Compact alpha-beta chess engine in 4 KB of Python for the make.fun
tiny-chess-01 competition: 0x88 board, iterative deepening with a fixed
node budget, quiescence search, transposition table, killer moves and
MVV-LVA ordering. Plays 16 games per trial against the house gauntlet
through the env at MAKEFUN_ENV_URL. Deterministic: fixed depth/node
budget, no clock, no randomness, no model calls.
